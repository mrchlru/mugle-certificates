# Сертификаты Mugle Rest

Замена Statix Bonus.

| Кто | Как попадает | Что делает |
| --- | --- | --- |
| Сотрудник | Ссылка `/c/…` от HR | Открывает карточку и показывает QR. Пароль не нужен |
| Управляющий | Логин на `/desk` | Сканирует QR и списывает сумму |
| HR | Логин на `/hr` | Выписывает сертификат и отправляет ссылку, смотрит списания |

HR вводит ФИО, логин, сегмент, номинал, цвет карточки, шаблон баннера, комментарий и срок. Остаток в начале равен номиналу. Ссылка, которая появляется после выпуска, и есть сертификат: цветная карточка в стиле старого Statix с QR. В QR зашита страница списания. Сегменты и картинки шаблонов HR настраивает в разделе «Оформление», на сводке сертификаты можно отфильтровать по сегменту.

Суммы хранятся в копейках. В интерфейсе это рубли.

## Запуск на компьютере

```bash
python -m venv .venv
.venv/Scripts/pip install -r requirements.txt
.venv/Scripts/python -m uvicorn bonus.main:app --host 0.0.0.0 --port 8080
```

Сайт: http://127.0.0.1:8080

Первый запуск создаёт входы и записывает их в `data/CREDENTIALS.txt`.

| Роль | Логин | Пароль |
| --- | --- | --- |
| HR | `hr` | `mugle-hr` |
| Управляющий | `manager` | `mugle-desk` |

Пароли HR и управляющего нужно сменить на странице «Пароль». Демо-сертификат Марии Соколовой виден в кабинете HR: там же ссылка, которую можно открыть без входа. Когда загрузите настоящую таблицу, в `.env` поставьте `SEED_DEMO=false` — на уже созданную базу это не влияет, демо просто не появится при чистом старте.

Проверка: `pip install pytest httpx`, затем `python -m pytest`

## Как устроен код

```
bonus/main.py          сайт и проверка /health
bonus/models.py        люди, сертификаты, журнал
bonus/services.py      выпуск, списание, отмена
bonus/importer.py      Excel и CSV
bonus/routes_*.py      страницы трёх разделов
bonus/templates        карточка, касса, кабинет HR
```

База по умолчанию — файл `data/bonus.db`. На Timeweb лучше PostgreSQL: см. `TIMEWEB.md`.

# ТЗ: распаковка подарочной карты (День рождения и бартер), версия для вашего стека

**Это ТЗ заменяет прежнее `TZ_BIRTHDAY_UNWRAP.md` и React-файлы** (`BirthdayUnwrap.tsx`, `birthday-unwrap.css`, `confetti.ts`): по странице «Выписать» видно, что приложение на серверных шаблонах и обычном JS (`app.js`, `tilt-core.js`, `color-picker.js`), без React. Старые файлы не использовать.

## 1. Задача

Перед показом карты клиенту показывать экран-распаковку: конверт, кнопка «Открыть», карта выезжает, конфетти, кнопка «Перейти к карте». Работает для карт, у шаблона которых включена распаковка. Остальные карты (в том числе «Карта сотрудника») не меняются.

Один механизм для двух видов:

| Вид | Для чего | Тексты |
|---|---|---|
| `birthday` | День рождения | «Вам подарок!» → «С днём рождения, Роман!» |
| `gift` | Бартер, «Спасибо» и любые другие подарочные | «Вам подарок!» → «Ваша карта, Роман», под заголовком название сегмента |

**Цвет фона берётся из цвета карточки** (то же значение, что хранится у сертификата и ставится в `--card`). Оранжевая карта даёт тёплое оранжевое свечение, тёмно-синяя синее, и так далее. Дополнительных настроек цвета нет: меняется цвет карточки, меняется экран. Проверено на оранжевом, тёмно-синем, красном, бирюзовом, тёмно-зелёном, жёлтом и чёрном (см. `reference-prototype.html`, внизу переключатели). Для слишком тёмных цветов свечение автоматически поднимается, для светлых текст на печати становится тёмным.

## 2. Файлы (в этой папке)

| Файл | Что это |
|---|---|
| `reference-prototype.html` | **Эталон.** Открыть в браузере, переключать «День рождения / Бартер» и цвета. В нём работает тот же код, что нужно подключить (в прототипе карта нарисована упрощённо, в приложении используйте реальный `.wallet-card`) |
| `gift-unwrap.js` | Готовая реализация, чистый JS, без зависимостей. Публичный интерфейс: `GiftUnwrap.mount({...})` |
| `gift-unwrap.css` | Стили, префикс `gu-`, на остальную страницу не влияют |

Использовать как есть. Не переписывать, не добавлять библиотеки анимации и конфетти.

**Проверено:** прототип с этим кодом прогонялся в Chromium (последовательность, 4 цвета, отсутствие ошибок скрипта). **Не проверено:** встраивание в ваше приложение (его кода у меня нет, я видел только страницу «Выписать»), реальные iPhone и Android.

## 3. Флажок в шаблонах (раздел «Оформление»)

У шаблона баннера добавить поле «Распаковка»: **нет / День рождения / Подарок** (по умолчанию «нет»). Имя в базе, например, `unwrap_kind` (`null | 'birthday' | 'gift'`), подгоните под принятые в проекте. Значение уходит в данные карты вместе с шаблоном.

Какие шаблоны включить, решаете вы. По списку из «Выписать» логично: «День рождения» → День рождения; «Бартер», «Бартер Москва-Стамбул», «Бартер Сибирские Огни», «Бартер Пинчи», «Бартер Си мама», «Бартер ХВВ», «Барер Джани ресторани» → Подарок; «Карта сотрудника» → нет.

В «Оформлении» рядом с шаблоном добавить кнопку «Посмотреть распаковку»: запускает `GiftUnwrap.mount` в режиме предпросмотра на карточке из превью (флаг запоминания не пишется).

## 4. Встраивание на странице карты клиента

1. Подключить `gift-unwrap.css` и `gift-unwrap.js` на странице карты клиента (после `app.js`), только там, где у карты `unwrap_kind` не пустой.
2. Шрифты **Unbounded** (700) и **Manrope** (400/600/800) подключить на этой странице (Google Fonts или файлами из `/static`). Если Manrope уже подключён, достаточно Unbounded.
3. Скрипт на странице карты (после отрисовки `.wallet-card`):

```js
var card = document.querySelector('.wallet-card');
if (card && DATA.unwrapKind && !DATA.unwrappedAt) {
  GiftUnwrap.mount({
    card: card,                          // существующий элемент: переносится на экран и возвращается на место
    kind: DATA.unwrapKind,               // 'birthday' | 'gift'
    color: DATA.cardColor,               // то же значение, что в --card
    firstName: firstNameFrom(DATA.fullName),
    segmentName: DATA.segmentName,       // для kind 'gift'
    brand: 'Mugle Rest',
    sealText: 'mr',
    onGo: function () { markUnwrapped(); }
  });
}
```

Где `DATA` значения из шаблона страницы (подставить через `data-` атрибуты или JSON, как принято в проекте). Все тексты вставляются через `textContent`, так что ФИО и название сегмента безопасны.

4. **Имя.** ФИО вводится в порядке «Фамилия Имя Отчество» («Марков Роман»). `firstNameFrom`: разделить по пробелам, если слов 2 и больше, взять второе, иначе не передавать (заголовок станет «С днём рождения!» / «Ваша карта»).
5. **Показывать один раз.** Предлагается так: при первом открытии показать, при нажатии «Перейти к карте» записать на сервере `unwrapped_at` у сертификата (запрос `POST` с токеном карты, по аналогии с остальными запросами, CSRF по вашей схеме), при следующих заходах сразу показывать карту. Если серверную запись делать не хотите, запасной вариант `localStorage` (ключ по номеру карты, в `try/catch`). Если нужно показывать каждый раз, убрать условие `!DATA.unwrappedAt`.
6. Карта **переносится**, а не копируется: наклон (`tilt-core.js`), штрихкод и все её обработчики продолжают работать. До раскрытия касания карты отключены, после раскрытия включаются. Блок штрихкода с `data-tilt-ignore` остаётся как есть.
7. Размер карты берётся из её фактических размеров (`offsetWidth/offsetHeight`) на момент вызова, при необходимости передайте `cardWidth` и `cardHeight`. Если ширина карты зависит от экрана, вызывайте `mount` после загрузки страницы.
8. Экран открывается поверх страницы на весь экран (на десктопе колонка 430px по центру). Прокрутка страницы под ним блокируется и возвращается после закрытия.

## 5. Последовательность (мс от нажатия «Открыть», уже заложена в код)

| Время | Что происходит |
|---|---|
| 0 | Печать увеличивается и исчезает, кнопка «Открыть» исчезает |
| 250 | Клапан откидывается **вверх углом** (широкая часть внизу), 900 мс |
| 650 | Клапан уходит за карту. **Одновременно** карта выезжает и растёт с 50% до 100% (1600 мс), а конверт плавно растворяется (1000 мс). К моменту полного размера карты конверта уже нет |
| 2350 | Карта на месте: конфетти, заголовок меняется, появляется «Перейти к карте →». Кнопки «Позже» нет |

Тайминги, кривые и размеры не менять без согласования.

## 6. Тексты

| Где | День рождения | Подарок (бартер и другие) |
|---|---|---|
| Метка сверху | Подарок | Подарок |
| До открытия | Вам подарок! / Mugle Rest приготовил кое-что ко дню рождения | Вам подарок! / Mugle Rest приготовил для вас карту |
| После | С днём рождения, Роман! / Ваша подарочная карта уже ждёт | Ваша карта, Роман / Бартер на все рестораны (название сегмента) |
| Кнопки | Открыть → Перейти к карте | то же |

Запасные формулировки для «Подарок», если захотите поменять: «Дарим вам карту», «Роман, это ваша карта». Меняется в одном месте: объект `TEXTS` в начале `gift-unwrap.js`.

## 7. Граничные случаи

- Цвет карточки произвольный (поле выбора цвета у вас свободное, плюс сохранённые цвета). Для любого значения палитра строится автоматически. Проверить минимум оранжевый, тёмно-синий, жёлтый, чёрный.
- На светлых цветах (жёлтый) печать получает тёмную надпись, конфетти строится из оттенков цвета карточки. У «Дня рождения» конфетти многоцветное.
- Нет имени: «С днём рождения!» / «Ваша карта». Длинное имя переносится на вторую строку.
- Низкие экраны (от 640px): подарок автоматически уменьшается, кнопка не перекрывает карту.
- `prefers-reduced-motion`: без анимации и конфетти, сразу раскрытая карта и кнопка.
- Если у карты уже есть своя тень, убрать правило `.gu__fit > * { filter: drop-shadow }`.
- Закрытие вкладки во время анимации: при возвращении начинается заново с «Открыть». `destroy()` останавливает таймеры и конфетти.

## 8. Чего не делать

- Не использовать старые React-файлы и не добавлять библиотеки.
- Не показывать распаковку для шаблонов без включённого флажка.
- Не менять вёрстку `.wallet-card`, положение штрихкода и логику наклона.
- Не вставлять пользовательские тексты через `innerHTML`.

## 9. Критерии приёмки

- Для карты с шаблоном «День рождения» и с любым бартерным шаблоном идёт распаковка, для «Карты сотрудника» нет.
- Фон совпадает по цвету с карточкой (оранжевая даёт оранжевое свечение и так далее).
- Порядок как в эталоне: клапан вверх углом, конверт исчезает до полного размера карты, потом конфетти.
- Карта видна целиком, кнопка её не перекрывает на высоте экрана от 640 до 900px.
- После раскрытия работают наклон и сканирование штрихкода.
- Повторный заход (если выбрано «один раз») сразу показывает обычную карту. Предпросмотр в «Оформлении» ничего не записывает.
- Ошибок в консоли нет, после закрытия экрана на странице не остаётся лишних элементов и обработчиков.

## 10. Проверка на устройствах

iPhone (Safari), Android (Chrome), десктоп Chrome/Safari/Firefox: нажатие «Открыть», плавность, конфетти, кнопка внизу, наклон, штрихкод, поворот экрана, два вида и 3–4 цвета.
